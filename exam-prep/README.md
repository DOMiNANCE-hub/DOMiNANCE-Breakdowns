# DOMiNANCE CVS Mock Examinations 02-04

Three complete 40-question, 60-minute single-best-answer examinations derived from the five completed CVS lecture tests. Each mock contains 13 Circulation 1, 7 Circulation 2, 7 Circulation 3, 7 Regional Circulation and 6 ECG questions. **No question ID repeats between these three mocks.** Each paper contains exactly 10 correct answers per letter A-D. Answers and detailed distractor explanations are in separate Markdown guides.

Source-of-truth material: completed lecture-test question files. These are question-bank derivatives and therefore repeat some previously available practice questions; they are not unseen originals. Academic sign-off by a lecturer is not claimed.

Files: `mock-02-exam.md` through `mock-04-answer-guide.md`, with machine-readable `mocks-02-to-04.json`.
