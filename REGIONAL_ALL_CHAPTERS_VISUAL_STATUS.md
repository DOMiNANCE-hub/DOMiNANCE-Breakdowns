## Release integrity
This is a **substantial image integration pass**, not full completion of all visual gaps. Images are hot-linked from Wikimedia Commons; availability and readability on a physical phone, especially in low bandwidth, still need real-device testing. The code regression suite verifies site behavior, not remote image delivery. The user requested that every meaningful lecturer figure's concept be represented and improved where necessary: use this inventory as a **remaining acceptance list**, not a claimed completion certificate.
