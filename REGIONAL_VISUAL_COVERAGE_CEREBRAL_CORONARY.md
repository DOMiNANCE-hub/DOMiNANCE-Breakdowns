## Image usage policy for these chapters

- Relevant images supplement and sometimes replace a misleadingly simplified graphic, but are not copies of lecture figures whose third-party rights may be unclear.
- Figure images are **click-to-enlarge within the same chapter**, using the existing `image-viewer.js`; attribution hyperlinks remain separate.
- Each externally hosted figure is loaded only as needed using `loading="lazy"`; reliability and legibility on physical phones require student testing.
- Prefer one figure per distinct teaching purpose; use more where each adds genuinely different anatomical or mechanistic information.
- Figures have correct Wikimedia source pages and publicly documented licences; share-alike requirements need to be respected for any subsequent derivative modifications.
